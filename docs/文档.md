# Abnormalities（异想体）

## 模块定位

管理**异想体实体**和**考验实体**的模组，依赖 GoldenBoughsLib 和 ResonatorCombatFramework。

## 项目结构

```
src/main/
├── java/architecture/abnormalities/
│   ├── client/renderer/entity/         — 实体渲染器（FruitOfUnderstandingRenderer, GrantUsLoveRenderer）
│   ├── common/
│   │   ├── entity/abnormalities/       — 异想体实体（TrainingRabbits）
│   │   ├── entity/ordeals/             — 考验实体接口 + 四色子包
│   │   │   ├── amber/                  — 琥珀色考验
│   │   │   ├── crimson/                — 深红色考验
│   │   │   ├── green/                  — 绿色考验
│   │   │   └── violet/                 — 紫色考验（FruitOfUnderstanding, GrantUsLove）
│   │   └── item/                       — 物品（ModEggItem）
│   ├── core/registry/                  — 注册表（EntityAttribute + 客户端 EntityRenderers）
│   ├── datagen/                        — 数据生成（Datagen, ItemModel, Sound, DatapackBuiltin, i18n/ZhCn, EntityTag）
│   └── init/                           — 初始化
│       ├── entity/                     — 实体类型（AbnormalitiesEntityTypes, OrdealsEntityTypes, ProjectileEntityTypes）
│       └── tag/                        — 标签（AbnormalitiesEntityTags）
│       AbnormalitiesCreativeModeTabs   — 创造模式标签页
│       AbnormalitiesEntityDataSerializers — 实体数据序列化器
│       AbnormalitiesSoundEvents        — 音效事件
│       AbnormalitiesSpawnEggItems      — 刷怪蛋
│
└── kotlin/architecture/abnormalities/
    └── core/                           — Abnormalities.kt (@Mod), AbnormalitiesClient.kt
    ├── event/                          — （空，预留）
    └── events/                         — （空，预留）
```

## 实体分类

| 类别    | 包                                | 说明                                        |
|-------|----------------------------------|-------------------------------------------|
| 异想体   | `common/entity/abnormalities/`   | 异想体实体（如 TrainingRabbits）                  |
| 考验·琥珀 | `common/entity/ordeals/amber/`   | 琥珀色考验实体                                   |
| 考验·深红 | `common/entity/ordeals/crimson/` | 深红色考验实体                                   |
| 考验·绿色 | `common/entity/ordeals/green/`   | 绿色考验实体                                    |
| 考验·紫色 | `common/entity/ordeals/violet/`  | 紫色考验实体（FruitOfUnderstanding, GrantUsLove） |

## 考验接口层次

```
IOrdealsEntity（顶层考验接口）
├── IOrdealsAmberEntity
├── IOrdealsCrimsonEntity
├── IOrdealsGreenEntity
└── IOrdealsVioletEntity
```

## 依赖

| 依赖                       | 用途              |
|--------------------------|-----------------|
| NeoForge 21.1            | 模组平台            |
| GoldenBoughsLib          | 核心库             |
| ResonatorCombatFramework | 战斗框架            |
| GeckoLib                 | 动画/模型           |
| MixinSquared             | Mixin 框架        |
| KMixin (KSP)             | Kotlin Mixin 生成 |
| Jade                     | 信息显示            |
| JEI (编译时)                | 物品配方            |
